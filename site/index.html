One loop. Six layers.

From raw signals to measurable behavior, each layer contributes a distinct part of the Agent system.

01 / DATA

Repository context

Code, issues, tests, CI logs and change history.

02 / MODELS

Code intelligence

Code LLM, repository retrieval and planning.

03 / TRAINING

Execution feedback

SFT, rejection fine-tuning and execution-feedback RL.

04 / INFERENCE

Generate patches

Completion, planning, patch generation and repair.

05 / HARNESS

Controlled delivery

Sandbox, shell, tests, Git and review tools.

06 / EVAL

Verified behavior

Tests, acceptance, regressions and review quality.

NON-NEGOTIABLES

Built to stay trustworthy.

The Agent is only as useful as the boundaries around it are clear.

01

Tests are the specification

A change is not complete until executable checks pass.

02

Small, reviewable diffs

Avoid unrelated rewrites and preserve user changes.

03

Expose failures

Never hide failed commands or skipped validation.
